# Iris Dataset – Chart Story

##  Project Overview

This project is a data visualization exercise using the Iris dataset.

The objective is to transform a small dataset into a simple visual story using Microsoft Excel.

##  Objectives

- Understand the Iris dataset
- Select appropriate chart types
- Create clear and labeled visualizations
- Extract insights from the data
- Present the findings as a short narrative

##  Tools Used

- Microsoft Excel
- Iris Dataset

##  Visualizations

### 1. Distribution of Iris Species

A pie chart showing the number of observations for each Iris species.

**Takeaway:** Each Iris species has 50 observations.

### 2. Average Petal Length by Species

A clustered column chart comparing average petal length across species.

**Takeaway:** Virginica has the longest petals on average, while Setosa has the shortest.

### 3. Average Petal Width by Species

A clustered column chart comparing average petal width across species.

**Takeaway:** Virginica has the widest petals on average, while Setosa has the narrowest.

### 4. Average Sepal Length by Species

A line chart comparing average sepal length across the three species.

**Takeaway:** Average sepal length increases from Setosa to Versicolor and is highest for Virginica.

##  Overall Insights

The Iris dataset contains three species with an equal number of observations. Although the number of flowers is the same for each species, their physical characteristics differ considerably. Virginica has the longest and widest petals on average, while Setosa has the smallest petals. The visualizations demonstrate how charts can transform numerical data into an easy-to-understand story.
